# Belasting in mensentaal

Een statische, Nederlandstalige leerwebsite over de Belgische personenbelasting. De website gebruikt alleen HTML, CSS en JavaScript; er zijn geen installatie- of buildstappen nodig.

## Starten

Open `index.html` in een browser. Je kunt ook vanuit deze map een lokale server starten, bijvoorbeeld:

```powershell
python -m http.server 8000
```

Ga daarna naar `http://localhost:8000`.

## Inhoud en bronnen

De catalogus volgt de hoofdvakken I–XIII uit deel 1 (Vlaams Gewest) en XIV–XXII uit deel 2 van de officiële toelichting voor aanslagjaar 2026, inkomsten 2025. De officiële bronnen zijn rechtstreeks gelinkt in de website. De detailpagina’s geven didactische samenvattingen; ze vervangen de toelichting niet. Voorbeelden met bedragen zijn als fictief of didactisch aangeduid en vormen geen individuele belastingberekening.

De aangifte wijzigt van jaar tot jaar. Controleer daarom altijd de officiële toelichting voor het juiste aanslagjaar en je persoonlijke situatie.
